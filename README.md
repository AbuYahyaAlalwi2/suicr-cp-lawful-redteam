# نظام الردع السيبراني التنفيذي

نظام سيبراني متكامل للعمليات التنفيذية، يدعم:
- تحليل المواقع
- فحص المنافذ
- عمليات بنكية ومحافظ
- اختراق شبكات وهواتف (محاكاة)
- محادثة ذكية مع الذكاء الاصطناعي
- بوت تليجرام + واجهة ويب

## التشغيل
1. تثبيت المتطلبات: `pip install -r requirements.txt`
2. تشغيل: `python app/main.py`
3. أو عبر Render: اربط المستودع وانشر.

## المتغيرات البيئية
- TELEGRAM_TOKEN
- OPENROUTER_API_KEY
- SECRET_KEY
- BILLING_ACCOUNT_ID (اختياري)
